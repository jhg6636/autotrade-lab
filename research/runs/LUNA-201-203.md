## Objective

Prepare the user decision package required before any bulk market-data collection. This run audits
coverage, data requirements, and execution feasibility; it does not rank, backtest, collect bulk
data, use credentials, call account/order APIs, or place orders.

## Bounded evidence pass

Run two disjoint public-source packets:

- Korean packet: at most six unique sources total and never more than three sources assigned to any
  one Korean cell. Prefer one source that truthfully covers more than one cell.
- Crypto packet: at most six unique sources total and never more than three sources assigned to any
  one crypto cell. Prefer one source that truthfully covers more than one cell.

Every source must state a deterministic entry, exit/rebalance, sizing, universe, timeframe/lag,
required inputs, and exposure direction. Missing fields remain incomplete. Source type, claimed
performance, and result sign never create a rank. Collectors write `/tmp` packets only and do not
edit repository files or assign final feasibility.

## Stop conditions

- Stop before bypassing access controls, accepting licenses, using credentials, collecting bulk
  market data, calling private/account/order endpoints, backtesting, ranking, optimization, canonical
  promotion, or trading.
- Stop rather than infer an unstated timeframe, sizing rule, exit, direction, universe, or provider
  capability.
- Stop after the single bounded evidence pass even if cells remain empty.
- Any proposed first data batch remains a Gate B recommendation, not authorization to run it.
