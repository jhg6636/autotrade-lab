작업 트랙별 실제 진행 상황

전략 연구 트랙

공통 데이터가 마련되기 전까지 아이디어에 순위를 매기지 않고 수집합니다.

  1. 스키마·카탈로그·중복 판별LUNA-001부터 LUNA-003까지 완료하고 검토했습니다.
  2. 학술 전략 조사LUNA-101을 결정론적 커버리지·출처 연결 감사와 함께 종료했습니다.
  3. 나머지 조사 트랙국내 조사는 준비 단계이며 실무자·커뮤니티·크립토 조사 범위가 남았습니다.
  4. 전략 승격·순위 선정공통 데이터 검증 전까지 닫혀 있습니다.

데이터 적격성 트랙

API가 호출된다는 사실과 합법적인 시점별 연구 데이터로 쓸 수 있다는 판단은 별도 게이트입니다.

  1. 제한적 제공자 검증크립토와 토스 표본으로 실제 응답 동작을 확인했습니다.
  2. 토스 데이터 계약 감사유용한 과거 일봉은 확인했지만 전체 상폐 유니버스와 이용 권리는 확정하지 못했습니다.
  3. 공식 소스 선정금융위원회 공공데이터포털 자료를 다음 제한 검증 대상으로 선정했습니다.
  4. Gate E1-DATA 결정수집기 준비는 끝났고 실제 공식 데이터 호출은 아직 실행하지 않았습니다.

실행 안전 트랙

고위험 투자는 다른 자금과 분리되고 손실 범위가 제한된 실험 계정에서만 허용합니다.

  1. 브로커·위험 경계계좌·주문 기능을 분리했고 실거래는 기본적으로 꺼져 있습니다.
  2. 국내 자산 제약상장주식·ETF 후보는 롱온리이며 공매도는 사용하지 않습니다.
  3. 모의투자 진입미시작 상태이며 적격 데이터셋과 검증을 통과한 후보가 필요합니다.
  4. 실자금 승인미시작 상태이며 투자금·최대손실·최대낙폭 한도를 먼저 정해야 합니다.

E1-DATA를 통과하면

확인된 과거 범위, 상폐종목 커버리지, 식별자, 페이지 처리, 기업행동 필드, 이용 권리를 검토합니다. 그다음에만 제한적 과거 데이터 수집·품질 검증 계획을 세웁니다.

E1-DATA가 실패하거나 불완전하면

광범위 국내 백테스트를 계속 닫아 둡니다. 정확히 부족한 소스를 보완하거나 별도 검토한 유료·계약형 데이터를 고려하되, 현재 종목 목록으로 과거 유니버스를 대체하거나 기업행동을 추측하지 않습니다.
